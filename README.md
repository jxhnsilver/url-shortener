# URL Shortener

### Описание

Сервис сокращения длинных URL-адресов до коротких ссылок. Предоставляет REST API для создания коротких ссылок и автоматически выполняет редирект при обращении к сгенерированным кодам.

### Технологии

* Backend: `.NET 10 (ASP.NET Core WebAPI), Entity Framework Core`
* База данных: `PostgreSQL`
* Архитектура: `Clean Architecture`
* Тестирование: `xUnit.v3`, `Moq`
* Документация API: `Swagger`

### Реализовано:

* REST API для создания коротких ссылок (POST /api/urls/shorten)
* Прямой редирект по короткому коду (GET /{code})
* Генерация коротких кодов c помощью Random (алфавит: a-z, A-Z, 0-9)
* Защита от коллизий: до 5 попыток генерации уникального кода
* Дедупликация: один и тот же URL -> один и тот же короткий код
* Unit-тесты для `Domain` и `Application` слоев с использованием `xUnit.v3` и `Moq`
